# 🍽️ پیش‌بینی مقدار انعام با یادگیری ماشین

این پروژه با هدف **پیش‌بینی مقدار انعام (Tip)** در رستوران با استفاده از اطلاعات مربوط به صورت‌حساب و ویژگی‌های مشتریان انجام شده است.

در این پروژه یک روند کامل و پایه‌ی **Machine Learning** را طی می‌کنیم؛ از بررسی و تحلیل داده‌ها گرفته تا آماده‌سازی داده، Feature Engineering، آموزش مدل و بررسی نتایج پیش‌بینی.

مدل استفاده‌شده در این پروژه **Multiple Linear Regression** است.


## 🎯 هدف پروژه

هدف اصلی پروژه این است که بتوانیم با استفاده از ویژگی‌های موجود، مقدار انعامی که یک مشتری پرداخت می‌کند را پیش‌بینی کنیم.


متغیر هدف در این پروژه:

```text
tip
```

## 📊 Dataset

برای این پروژه از Dataset معروف `tips` که در کتابخانه‌ی **Seaborn** وجود دارد استفاده شده است.

Dataset شامل اطلاعات مربوط به صورتحساب‌های رستوران و مقدار انعام مشتریان است.

برخی از ستون‌های اصلی Dataset:

| ستون         | توضیح                     |
| ------------ | ------------------------- |
| `total_bill` | مبلغ کل صورت‌حساب         |
| `tip`        | مقدار انعام               |
| `sex`        | جنسیت مشتری               |
| `smoker`     | سیگاری بودن یا نبودن      |
| `day`        | روز هفته                  |
| `time`       | زمان غذا، Lunch یا Dinner |
| `size`       | تعداد افراد حاضر در میز   |


## 🧰 کتابخانه‌های استفاده‌شده

این پروژه با Python انجام شده و از کتابخانه‌های زیر استفاده می‌کند:

* **NumPy** → محاسبات عددی
